# Blender-Localization-Simulation
Open-source 3D scene datasets modeled via Blender for wireless localization survey.

You need to download Blender first: https://www.blender.org

Blender-OSM if needed:https://prochitecture.gumroad.com/l/blender-osm

Download Mitsuba-Blender next for creating scenario: https://github.com/mitsuba-renderer/mitsuba-blender/releases/tag/latest

Install Mitsuba-Blender: https://github.com/mitsuba-renderer/mitsuba-blender/wiki/Installation-&-Update-Guide

Find the location of Mitsuba-Blender in your computer and then find out a folder called "exporter". Change the "exporter" 
with released.

building_generator.py is an example scripts for batch generating scenes. Just open and run it in Blender.
